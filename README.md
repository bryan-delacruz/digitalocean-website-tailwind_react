# DigitalOcean Home Page — React + Tailwind

A recreation of the DigitalOcean home page (2022), built to practice Tailwind CSS in a React app.

**Live:** [digitalocean-web-tailwind-react-bdlc.vercel.app](https://digitalocean-web-tailwind-react-bdlc.vercel.app/)

> Study project. Not affiliated with DigitalOcean.

## What's in it

- 12 section components: two navigation bars, hero, stats, features, cloud, scale, slides, community, blog panel and footer.
- Responsive layout with Tailwind breakpoints (`sm`, `md`, `lg`).
- Cascadia Code as the monospace font.

## Stack

React, Tailwind CSS, PostCSS. Bootstrapped with Create React App (`npm install && npm start`).
